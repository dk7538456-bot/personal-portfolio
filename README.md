# Dipanshu Khatri — Personal Portfolio

A responsive, mobile-first portfolio for presenting Dipanshu's cloud learning journey, skills, and projects.

## Run locally

Open `index.html` in a browser. The page uses plain HTML, CSS, and JavaScript; there is no build step.

## Customize

- Update the profile copy, contact link, and project links in `index.html`.
- Keep the project descriptions aligned with work that has actually been completed.
- Adjust colors and layout in `styles.css`.
- The optional Google Fonts import falls back to system sans-serif fonts when offline.

## Publish with GitHub Pages

1. In the repository settings, open **Pages**.
2. Choose **Deploy from a branch**, select `main` and the repository root, then save.
3. Use the Pages URL shown by GitHub after deployment completes. When the repository is named `dk7538456-bot.github.io`, GitHub Pages can use the account root URL.

## Accessibility and behavior

The layout uses semantic landmarks, a skip link, keyboard-friendly navigation, visible focus from browser defaults, and a reduced-motion preference. The mobile menu is controlled by a button with an expanded state.
